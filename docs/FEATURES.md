# 機能一覧

実装したい機能の一覧。決まった順番はなく、実際に使いながら、必要になったものから順に実装する。
各項目は単独で実装・リリースできる大きさにしてある。大きさは目安（小：1 回の作業、中：数回、大：いくつかに分けて進める）。

## 決めたこと

- **曲のファイル**：楽譜ソフト（MuseScore など）で書き出したファイルを使う。演奏を録音した MIDI は想定しない。
  - 形式は **MusicXML** を主にする。音の綴り（♯・♭）、右手・左手の段、声部、拍子、小節線が入っていて、
    楽譜の表示と判定の両方にそのまま使えるため。MIDI ファイルは必要になったら追加する。
  - 右手・左手は、ピアノ譜の上の段・下の段で分ける。
- **判定**：ms 単位で測りつつ、ある程度合っていれば OK にする。音ゲーのように判定ランクごとの幅を用意する
  （例：PERFECT ±30ms / GREAT ±60ms / GOOD ±100ms / それ以上は MISS。幅は設定で変えられるようにする）。
  テンポの揺れを許す判定（自分のテンポに追従する）は、必要になったら追加する。

## 技術メモ

- 公開は GitHub Pages の静的サイトのままで実現できる。サーバーは不要。
- 鍵盤を押した時刻は電子ピアノからの信号に付く時刻を使うので正確。ずれるのはスマホから出る音の方で、補正値（設定の「音のずれの補正」）で差し引いている。
- VexFlow は約 720KB あり、リズムモードを開いたときだけ読み込んでいる。OpenSheetMusicDisplay を使う場合も同じように必要なときだけ読み込む。
