# 読譜ドリル

五線譜に出た音符を、画面のピアノ鍵盤で答える読譜トレーニングです。
スマホのブラウザで動き、ホーム画面に追加すればアプリのように使えます。

## いまできること

- ト音記号・ヘ音記号・大譜表からの単音・和音（2〜3 音）の出題
- 加線の本数、♯・♭の有無、判定方法（音名だけ／高さまで）の設定
- 時間制限なしの練習モードと、60秒チャレンジ（設定ごとに自己ベストを記録）
- リズムモード：メトロノームに合わせて 1〜2 小節のフレーズを弾き、音ごとの正誤とタイミングのずれ（ms）を表示。BPM の変更、音の遅れの補正、正解を BPM どおりに鳴らす「お手本」に対応
- 間違えやすい音の記録と、その音を多めに出す出題
- 記録はブラウザの localStorage に保存（端末間では共有されない）
- 電子ピアノを USB でつなぎ、弾いた鍵盤で答える（Web MIDI。Android / PC の Chrome など）。和音は同時に弾いて答える

## 動かし方

Node.js（22.12 以降）が必要です。

```sh
npm install
npm run dev     # 開発サーバー（表示された URL を開く）
npm test        # 単体テスト
npm run build   # dist/ にビルド
```

## 公開

GitHub Actions（`.github/workflows/pages.yml`）が GitHub Pages に公開します。公開されるページは次のとおりです。

| URL | 中身 |
|---|---|
| https://mint149.github.io/dokufu-drill/ | 最新のリリース（いちばん新しい `v*` タグ） |
| https://mint149.github.io/dokufu-drill/next/ | `main` の最新（開発版） |
| https://mint149.github.io/dokufu-drill/v0.0.1/ など | 各リリースをそのまま固定 |

- `main` に push すると `/next/` が更新されます。トップのページは変わりません。
- `/next/` で確認して問題なければ、タグを付け、リリース用の空コミットと一緒に push するとトップのページが新しい版に切り替わります。

```sh
git tag v0.2.0
git commit --allow-empty -m "v0.2.0 をリリース"
git push origin main v0.2.0
```

タグだけを push しても公開はされません。GitHub Pages は同じコミットを公開し直さないため、新しいコミットを main に push して公開します。

設定と記録（localStorage）は全バージョンで共通です。保存形式を変えるときは、古い版でも壊れないように移行処理を入れるかキーのバージョンを上げてください。
